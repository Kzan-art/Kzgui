Public Profile Lookup

Recherche de données publiquement accessibles. Aucun mot de passe, session ID, token ou contournement n'est demandé.

ROBLOXRecherche réelle via l'API publique Roblox.
DISCORDMode interface : Discord ne fournit pas une recherche publique arbitraire de comptes.
FACEBOOKMode interface : données accessibles uniquement via les mécanismes publics autorisés.
SNAPCHATMode interface : pas de recherche privée ou de contournement.
[KZ4N] ready [SCOPE] public/read-only [NOTE] Les recherches inter-plateformes ne sont pas utilisées pour déduire l'identité réelle d'une personne.

Username lookup

Pour Roblox, le nom est recherché via l'API publique officielle. Pour Discord/Facebook/Snapchat, l'interface indique simplement la disponibilité de fonctions publiques.

kz4n@lookup:~$ waiting...
